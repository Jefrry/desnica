# 03: Проверить отображение публикаций

Подтвердить [критерии приёмки](../spec.md) после реализации задач 01–02. Выполнять после отдельного поручения на реализацию.

## Работа

- Добавить регрессионную проверку реального пути обработки содержимого: исходная строка CMS → очищенное форматирование и оглавление. Убедиться, что проверка обнаруживает первоначальный дефект со звёздочками.
- Сравнить один набор примеров с предпросмотром установленной Strapi: основной Markdown, расширения, HTML и оговорённые исключения.
- Проверить потенциально опасные HTML и URL, относительные изображения, повторяющиеся заголовки и обычный текст.
- Проверить статью в браузере на широком экране и при ширине 320–390 CSS px, первоначальную загрузку и внутреннюю навигацию, прямой hash, переходы из оглавления и историю браузера.
- Выполнить lint, проверку типов и сборку проекта. Записать результаты и фактические ограничения в ответ задачи.

## Готово, когда

- Критерии приёмки подтверждены результатами проверок; исключения из совпадения с предпросмотром соответствуют спецификации.
- Проверки проекта проходят; отсутствуют оставленные временные средства диагностики.
