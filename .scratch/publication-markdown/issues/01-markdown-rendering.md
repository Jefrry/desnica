# 01: Добавить обработку Markdown публикации

Реализовать обработчик полного содержимого по [спецификации](../spec.md). Выполнять после отдельного поручения на реализацию.

## Работа

- Подключить в `apps/web` явные зависимости обработки Markdown и очистки HTML, подходящие для серверного рендеринга Nuxt и браузера. Использовать движок `markdown-it` и совместимые настройки и расширения предпросмотра Strapi.
- Предусмотреть единый результат обработки для тела статьи и оглавления. Существующие текстовые блоки не представляют вложенное форматирование и не должны ограничивать новый путь Markdown.
- Нормализовать уровни заголовков по спецификации; присвоить уникальные стабильные идентификаторы с учётом повторяющихся и русскоязычных заголовков.
- Согласовать очистку HTML с предпросмотром, исключая видеовставки. Обработать URL изображений относительно CMS, сохраняя локальные якоря и обычные ссылки.

## Готово, когда

- Обработчик поддерживает согласованный синтаксис и возвращает очищенный результат и соответствующее ему оглавление.
- Поведение на сервере и в браузере совпадает; обработка не зависит от доступности глобального `window` на сервере.
- Проверены нормализация заголовков, повторяющиеся идентификаторы, безопасный HTML и URL.

## Answer

Реализовано 20 октября 2026 года. Добавлен независимый от Nuxt runtime обработчик
`renderPublicationMarkdown(content, cmsBaseUrl)`, возвращающий очищенный `html`
и `toc`. Настройки Markdown, расширения, подсветка и сноски согласованы с
установленным предпросмотром Strapi 5.55.1. Используется DOMPurify с серверным
DOM-окружением; видеовставки исключены, опасные URL и атрибуты удаляются.

Markdown- и HTML-заголовки нормализуются в одном очищенном дереве; H2 образуют
оглавление, все заголовки получают уникальные стабильные идентификаторы.
Относительные адреса изображений разрешаются относительно переданного публичного
адреса CMS; ссылки и локальные якоря сохраняются.

Пройдены 9 тестов, включая браузерную сборку в DOM-окружении и сравнение с
серверным результатом, lint, typecheck web/CMS и production-сборка web/CMS.
Два независимых ревью выполнены: по Standards замечаний нет; по Spec исправлена
потеря пробела при `<br>` внутри заголовка и добавлен регрессионный тест.
Открытых замечаний нет. Коммит не создавался по поручению пользователя.

Подключение обработчика к странице и оформление остаются в пункте 02.
