# 05: Выбор и чтение документов

**What to build:** Посетитель выбирает документ, читает его текстовую версию и скачивает подтверждённый файл при наличии; ссылка и история браузера сохраняют выбранный материал.

**Blocked by:** 02.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [x] Перенесена страница документов с текущим перечнем, текстовыми версиями и оформлением.
- [ ] Выбор документа отражается в существующем query-параметре document и якоре чтения; прямое открытие ссылки показывает нужный материал.
- [x] Переходы назад и вперёд восстанавливают выбор, а управление фокусом соответствует текущему поведению.
- [ ] Текстовая версия доступна независимо от наличия файла. Для существующего файла корректны скачивание, формат и размер; отсутствующий файл не превращается в неработающую ссылку.
- [x] Неизвестное значение выбора обрабатывается по поведению текущей версии; содержимое не меняется на выдуманный материал.
- [ ] Проверены чтение, переключение, скачивание при наличии, мобильный экран, клавиатура и увеличение текста.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.

## Answer

6 ноября 2026 реализована `/about/documents`: три исходных документа и их
текстовые версии, оглавление, CTA контактов, адаптивные стили. PHP отдаёт
выбранный материал без JavaScript; JS сохраняет `document`, якорь и прочие
query-параметры, восстанавливает выбор и фокус при Back/Forward.
Отсутствующие файлы не получают ссылок; подтверждённый локальный файл можно
подключить через поле `file` со считыванием действительного размера и формата.

ESLint, типы web/cms, 15 тестов (12 существующих и 3 DOM), разбор CSS
и `git diff --check` прошли. Отдельные ревью Standards и Spec завершены,
ошибка серверного выбора `document=0` исправлена. Отмеченные пункты об истории
и фокусе проверены в DOM; визуальная приёмка пока не выполнена.

17 HTTP-проверок остановились на `EACCES 127.0.0.1:8080`, Podman недоступен,
PHP CLI отсутствует. Прямые открытия в WordPress, выполнение PHP, скачивание
при появлении файла, мобильный экран, клавиатура и масштаб 200% требуют
проверки работающего сайта. Поэтому статус `ready-for-human`, а не `resolved`.
Коммитов не создано, прежние изменения окружения сохранены.
