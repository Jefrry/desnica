# 07: Каталог услуг и разработка локальных документов

**What to build:** Посетитель открывает каталог четырёх услуг, читает страницу разработки локальных документов и переходит к контактам.

**Blocked by:** 02, 04.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Каталог содержит ровно четыре текущие услуги с прежними названиями, ссылками и оформлением.
- [ ] Страница разработки локальных документов перенесена целиком с текущими текстами, блоками, FAQ и материалами.
- [ ] Главный переход обращения приводит к работающей странице контактов без формы и контекста обращения.
- [ ] Оба адреса открываются напрямую и после обновления, доступны из общей навигации и каталога.
- [ ] Проверены мобильное отображение, клавиатура и интерактивные элементы; новые услуги и редактор раздела в админке не добавлены.
- [ ] Общие повторяющиеся элементы услуг пригодны для следующих страниц без изменения бизнес-содержания уже перенесённой услуги.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.

## Answer

7 ноября 2026 реализованы `/services` и `/services/local-documents` по прямому
указанию пользователя. Каталог и меню берут названия и ссылки из одного списка
четырёх услуг. Страница локальных документов сохраняет исходный текст, описания
материалов, связанные услуги и два вопроса FAQ. Первый ответ открыт при загрузке.
Для раскрытия ответов используются нативные элементы `details` и `summary`.
Кнопки обращения ведут на `/contacts`. Детальные страницы ОДИ, согласования
проектов и паспорта доступности относятся к задачам 08 и 09.

19 существующих тестов Nuxt и DOM, ESLint, проверка типов Nuxt и Strapi и разбор
CSS прошли. Замечания ревью по общему FAQ, сетке связанных услуг, отступу
в карточках и подключению jsdom исправлены. Коммит не создан.

HTTP-проверки остановились на `EACCES 127.0.0.1:8080`. Podman недоступен из
терминала, браузер вернул `ERR_CONNECTION_REFUSED`, PHP CLI отсутствует.
Для приёмки работающего WordPress запустить
`node --test apps/wordpress/checks/services-http.test.mjs` из корня проекта.
В браузере сверить страницы с Nuxt на ширинах 1440, 390 и 320 px и при масштабе
200%. Проверить переходы из меню и каталога, якорь списка, обновление страниц,
переход на контакты и работу FAQ через Tab, Enter и Space. При открытии второго
ответа первый должен закрыться, а фокус остаться на выбранном вопросе.
