# 07: Каталог услуг и разработка локальных документов

**What to build:** Посетитель открывает каталог четырёх услуг, читает страницу разработки локальных документов и переходит к контактам.

**Blocked by:** 02, 04.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Каталог содержит ровно четыре текущие услуги с прежними названиями, ссылками и оформлением.
- [ ] Страница разработки локальных документов перенесена целиком с текущими текстами, блоками, FAQ и материалами.
- [ ] Главный переход обращения приводит к работающей странице контактов без формы и контекста обращения.
- [ ] Оба адреса открываются напрямую и после обновления, доступны из общей навигации и каталога.
- [ ] Проверены мобильное отображение, клавиатура и интерактивные элементы; новые услуги и редактор раздела в админке не добавлены.
- [ ] Общие повторяющиеся элементы услуг пригодны для следующих страниц без изменения бизнес-содержания уже перенесённой услуги.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.
