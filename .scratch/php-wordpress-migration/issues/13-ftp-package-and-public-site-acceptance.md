# 13: Готовый комплект для FTP и локальная приёмка

**What to build:** Владелец получает полностью готовую и проверенную пользовательскую часть сайта и комплект для загрузки в существующий WordPress. Локальная установка по инструкции подтверждает работу всех страниц и публикаций без изменения базы и администратора принимающей установки.

**Blocked by:** 03, 04, 05, 06, 07, 08, 09, 11, 12.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] После завершения этой задачи вся пользовательская часть сайта готова: перенесены все информационные разделы, главная, архив и статьи, документы, отчёты, контакты, правовая страница и пользовательские переходы. Это готовый работающий сайт, а не набор макетов или заготовок.
- [ ] Подготовлен комплект темы, плагина сайта, бесплатного Markdown-редактора и готовых зависимостей. Для работы на хостинге не нужны Node.js, Composer или Docker.
- [ ] Комплект установлен по инструкции в отдельный WordPress 6.7.1 с существующей базой, пользователем и контрольными данными. Соединение с базой, администратор и контрольные данные сохранились; локальная база не импортировалась поверх принимающей.
- [ ] По всем публичным адресам проверены прямое открытие, обновление, переходы, изображения, документы/отчёты и отсутствие локальных URL. Основные экраны сопоставлены с текущим сайтом.
- [ ] Проверены ширины 1440, 390 и 320 пикселей, увеличение до 200%, меню, клавиатура, фокус, заголовки, 404 и пустые/ошибочные состояния. Непроведённые проверки вспомогательными устройствами не объявлены выполненными.
- [ ] Сквозные сценарии автора и посетителя, права роли, черновики, расширенный Markdown, оглавление, сортировка, архив и возврат к карточке прошли в устанавливаемом комплекте.
- [ ] Проверены запрет индексации по умолчанию, отсутствие ошибок PHP/JavaScript и сохранность старой реализации и её данных.
- [ ] Короткие инструкции локального запуска/обновления проверены фактическим выполнением через Podman; проверка только через Docker не подменяет этот результат. FTP-установка также проверена. Описаны резервная копия перед активацией, активация плагинов/темы, минимальная настройка маршрутов и возврат к прежней теме.
- [ ] Записаны результаты проверки и ограничения. Неустранённый дефект, мешающий согласованному пользовательскому сценарию, не скрыт за пометкой «готово». Готовность локального комплекта не выдается за выполненную установку на Timeweb.
