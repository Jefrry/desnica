# 14: Установка и проверка на Timeweb

**What to build:** Готовая пользовательская часть сайта установлена в существующий WordPress на Timeweb и проверена по реальным адресам. Владелец может пользоваться сайтом и редактором на выбранном хостинге.

**Blocked by:** 13.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Внешняя предпосылка: доступна принимающая установка Timeweb и разрешённый способ её настройки. При отсутствии доступа задача остаётся открытой; локальная проверка не подменяет проверку хостинга.
- [ ] Проверены фактические WordPress 6.7.1, PHP 8.x, MySQL, активные плагины и настройки адресов; при расхождении с локальной средой совместимость установочного комплекта проверена, несовместимость не обходится молча.
- [ ] Проверено, не меняют ли точную версию ядра автоматические обновления WordPress или панели. Требование строго 6.7.1 соблюдено; переход на другую версию не производится без изменения требования.
- [ ] До активации подготовлена резервная копия. Тема и плагины установлены штатным способом с сохранением существующей конфигурации подключения, администратора и данных; локальная база и секреты не перенесены поверх хостинговых.
- [ ] На хостинге проверены главная, все информационные разделы, документы/отчёты, архив, статья, контакты, правовой якорь и 404. Прямые адреса и обновление страниц работают; файлы и изображения доступны.
- [ ] На хостинге проверены вход автора, создание/сохранение/предпросмотр/публикация Markdown, изображение и публичное отображение; черновики закрыты от анонимного посетителя.
- [ ] Проверены мобильная навигация, запрет индексации по умолчанию, отсутствие локальных URL и явных ошибок PHP/JavaScript.
- [ ] Короткая инструкция соответствует фактической установке и обновлению файлов на Timeweb. Зафиксированы результаты проверки и рабочие адреса без публикации секретов.
- [ ] Итог: полностью готовая пользовательская часть работает на Timeweb. При внешних блокировках или существенных дефектах задача не закрывается как успешно установленная.
