# 01: Локальный запуск WordPress и первая PHP-страница

**What to build:** Владелец запускает отдельную PHP-версию Ресурсного центра в контейнерах через Podman и открывает первый экран собственной темы. Дальнейшие изменения можно проверять по очень короткой инструкции для Podman, сохраняя старый проект и локальные данные.

**Blocked by:** None (can start immediately).

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Проверены доступность Podman, выбранный способ запуска Compose и работоспособность необходимого окружения Windows; отдельно указано, что установлено, что отсутствует и что не удалось проверить. При необходимости подготовлена инструкция установки; запуск не объявлен успешным без фактической проверки. Отсутствие Docker не считается блокировкой, Docker Desktop и Docker Engine не обязательны.
- [ ] В отдельном окружении запускаются строго WordPress 6.7.1, PHP 8, веб-сервер и настоящая MySQL с чистой базой. Конкретные версии закреплены; неизвестная конфигурация Timeweb не выдаётся за подтверждённую.
- [ ] Собственная классическая PHP-тема активируется и показывает первый экран с брендом «Ресурсный центр»; это не стандартная тема WordPress и не работающая поверх Nuxt страница.
- [ ] Новая реализация расположена рядом со старой. Исходники, конфигурация, зависимости и база старого стека не удаляются и не перенастраиваются.
- [ ] После остановки и повторного запуска сохраняются пользователь WordPress, проверочная запись и загруженный файл. Пример проверки не становится автоматическим наполнением обычной чистой базы.
- [ ] Изменение исходника темы видно после обновления страницы без пересборки; файлы подключены с компьютера. Правки окружения применяются документированной пересборкой без удаления данных.
- [ ] Очень короткая инструкция содержит фактически проверенные команды для Podman: первый запуск, адреса сайта и админки, обычное применение правок, пересборку, остановку и повторный запуск. PHP и Composer в Windows не требуются для работы контейнерного сайта.
- [ ] В фактическом окружении Podman на Windows проверены подключение исходников, сеть сервисов, постоянные тома и сохранность MySQL при обновлении. Проверка только через Docker не подменяет эту приёмку.
- [ ] Запрет индексации новой версии включён по умолчанию и проверен через публичный ответ. Секреты окружения не включены в поставляемые исходники.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.
- Позднее уточнение пользователя: локальные контейнеры будут запускаться через Podman; все команды и проверки этой задачи должны учитывать это.
