# 12: Архив публикаций и возвращение к карточке

**What to build:** Посетитель просматривает «Новости», открывает статью, возвращается к исходной карточке архива и видит последние публикации на главной.

**Blocked by:** 10.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Архив показывает только опубликованные записи по шесть на странице, сортирует по календарной дате по убыванию, затем по ID WordPress по возрастанию.
- [ ] Пагинация сохраняет прежний параметр page; некорректные, повторяющиеся или выходящие за диапазон значения обрабатываются по текущему пользовательскому поведению.
- [ ] Переход в статью и возврат сохраняют исходную страницу архива и фокус/якорь нужной карточки, используя новые идентификаторы WordPress без зависимости от Strapi.
- [ ] Главная получает последние опубликованные записи из той же базы, без отдельного демонстрационного источника. Черновики не попадают ни в архив, ни на главную.
- [ ] Пустая база показывает корректное пустое состояние; отсутствующая статья даёт 404. Техническая ошибка отличается от пустого результата и не раскрывает внутренние сообщения.
- [ ] Проверен сценарий с двумя страницами архива, одинаковыми датами, обложками и без них, прямыми ссылками и back/forward. Проверочные записи не создаются скрыто при обычном запуске.
- [ ] Карточки, пагинация и возврат работают на мобильном экране и с клавиатуры.
- [ ] В сочетании с завершёнными задачами 01–11 реализована вся пользовательская часть, включая публикации. Её итоговая готовность подтверждается приёмкой задачи 13.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.

### Реализация

Архив `/news` показывает до шести опубликованных записей. Главная показывает
первые три из той же выборки. Ссылки из архива сохраняют страницу и ID записи
WordPress. Архив различает пустую коллекцию, страницу вне диапазона и ошибку
загрузки. Проверочные данные создаются только при явном запуске теста.

DOM-проверка восстановления фокуса прошла. HTTP-проверка и Chromium ожидают
доступа к локальному WordPress и Podman. Команды запуска описаны в
[инструкции проверок](../../../apps/wordpress/checks/README.md#проверка-пункта-12).
