# 11: Расширенный Markdown и оглавление статьи

**What to build:** Автор публикует сложный Markdown, а посетитель читает его без потери форматирования и перемещается по согласованному оглавлению статьи.

**Blocked by:** 10.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] На существующем наборе примеров проверены форматирование, переносы строк, ссылки, изображения, таблицы, зачёркивание, сокращения, списки определений, emoji, сноски, вставки, выделения, нижние/верхние индексы, warning/tip и подсветка кода.
- [ ] Недостающие в готовом редакторе возможности обеспечены интеграцией сайта; нет молчаливого сокращения поддержанного синтаксиса. Неразрешённые существенные отклонения не объявляются готовностью.
- [ ] Единственный H1 принадлежит странице; наличие H1 в содержимом вызывает согласованный сдвиг уровней не выше H6.
- [ ] Оглавление строится по итоговым H2 и ведёт к существующим устойчивым уникальным якорям. Проверены повторяющиеся, пустые и HTML-заголовки.
- [ ] Статья и оглавление получены из одной обработки Markdown; уже сформированный HTML не интерпретируется повторно как Markdown.
- [ ] Сохраняется очистка опасных тегов, обработчиков событий и URL; изображения и обычные безопасные ссылки работают.
- [ ] Проверены сохранение и повторное открытие сложного Markdown, предпросмотр и публичное отображение. Семантическая эквивалентность важнее побайтового совпадения HTML разных библиотек.
- [ ] Есть проверки контракта «Markdown → очищенная статья и оглавление» на существующем корпусе и сквозная проверка в браузере на настольной и мобильной ширине.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.

### Реализация

Добавлен серверный рендер расширенного Markdown и оглавления из одного
результата. Подсветка запускается в браузере из локального ресурса.
Подготовлены проверки контракта на общем корпусе, HTTP-проверка авторского
сценария и браузерный сценарий Chromium на 1440, 390 и 320 px.

Приёмка остаётся открытой. Podman блокирует подключение к сокету, HTTP-сайт
недоступен. Проверка сборки и подсветки в JSDOM прошла. Полное совпадение
типографики и автоматического распознавания доменов без схемы с Markdown-It
не подтверждено.
