# 02: Главная страница и навигация сайта

**What to build:** Посетитель открывает перенесённую главную страницу, пользуется общей навигацией на компьютере и телефоне и получает понятную страницу 404. На этой основе следующие страницы подключаются без повторной разработки общего интерфейса.

**Blocked by:** 01.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Главная страница сохраняет текущие тексты, порядок блоков, оформление, типографику, изображения и поведение; отсутствующие материалы не заменены выдуманными реальными фактами.
- [ ] Общие шапка, подвал и навигация сохраняют шесть разделов и текущие дочерние пункты; бренд в интерфейсе — «Ресурсный центр».
- [ ] Мобильное меню открывается и закрывается, поддерживает Escape, ограничение фокуса внутри открытого меню и возврат фокуса на кнопку. Настольные выпадающие меню работают с клавиатуры.
- [ ] Неизвестный адрес возвращает настоящий HTTP 404 и оформленный экран ошибки. Прямое открытие и обновление главной работает без серверного Node.js.
- [ ] Блок последних публикаций при пустой базе показывает корректное пустое состояние, без моковых статей. Подключение опубликованных записей выполняется задачей 12.
- [ ] Проверены ширины 1440, 390 и 320 пикселей, увеличение до 200%, видимый фокус, основные ссылки и отсутствие ошибок PHP/JavaScript.
- [ ] Ссылки на ещё не перенесённые разделы сохраняют целевые адреса; содержимое этих разделов реализуется отдельными задачами и не объявляется готовым в этой задаче.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.
