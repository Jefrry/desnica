# 06: Годовая отчётность

**What to build:** Посетитель выбирает годовой отчёт, читает его разделы и возвращается к выбранной версии по ссылке или через историю браузера.

**Blocked by:** 02.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Перенесены текущие отчёты, выбор года и отображение содержания.
- [ ] Сохраняются query-параметр year и якоря разделов; прямое открытие и обновление ссылки восстанавливают нужный отчёт.
- [ ] Переходы назад и вперёд корректно восстанавливают состояние; клавиатурная навигация и фокус не теряются при переключении.
- [ ] Текстовое чтение не зависит от файла; скачивание доступно только для существующего подтверждённого файла.
- [ ] Неизвестный год и отсутствие материалов обрабатываются как в текущем сайте без автоматического выдумывания отчётов.
- [ ] Проверены настольная и мобильная версии, длинное содержимое, переходы по разделам и увеличение текста.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.
