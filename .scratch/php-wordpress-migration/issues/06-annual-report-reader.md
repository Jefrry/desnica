# 06: Годовая отчётность

**What to build:** Посетитель выбирает годовой отчёт, читает его разделы и возвращается к выбранной версии по ссылке или через историю браузера.

**Blocked by:** 02.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [ ] Перенесены текущие отчёты, выбор года и отображение содержания.
- [ ] Сохраняются query-параметр year и якоря разделов; прямое открытие и обновление ссылки восстанавливают нужный отчёт.
- [ ] Переходы назад и вперёд корректно восстанавливают состояние; клавиатурная навигация и фокус не теряются при переключении.
- [ ] Текстовое чтение не зависит от файла; скачивание доступно только для существующего подтверждённого файла.
- [ ] Неизвестный год и отсутствие материалов обрабатываются как в текущем сайте без автоматического выдумывания отчётов.
- [ ] Проверены настольная и мобильная версии, длинное содержимое, переходы по разделам и увеличение текста.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.

## Answer

6 ноября 2026 реализована `/about/reports` по прямому указанию пользователя,
несмотря на ожидающую приёмку задачи 02. Перенесены три исходных года
2025/2024/2023, демонстрационные тексты и обложки, выбор года, архив,
метаданные и адаптивные стили. `year`, якоря reader и разделов, Back/Forward,
фокус и статус выбора обрабатываются JavaScript. PHP отдаёт выбранный текст
и позволяет выбирать год без JavaScript. Общий разбор query сохраняет
поведение исходной версии для пустого/повторного параметра и строки `0`.
Неизвестный год не создаёт отчёт. Файлов нет, ложных ссылок скачивания нет;
используется существующая проверка подтверждённого файла темы.

19 тестов (12 старого стека и 7 DOM документов/отчётов) прошли. ESLint и
проверка типов выполнены установленными локальными инструментами; запуск
через pnpm не смог получить метаданные менеджера пакетов из сети. CSS
разобран PostCSS. Ревью Standards: 0 замечаний; Spec: 0 дефектов реализации,
1 незавершённая область приёмки.

26 HTTP-проверок остановились на `EACCES 127.0.0.1:8080`; подключение Podman
запрещено средой, PHP CLI отсутствует. Выполнение PHP, реальный браузер,
мобильные ширины, длинное содержание, клавиатура, масштаб 200% и реальное
скачивание не подтверждены. Поэтому задача ожидает приёмки `ready-for-human`,
а не `resolved`. Коммитов не создано; прежние изменения окружения сохранены.
