# 04: Контакты и правовая страница

**What to build:** Посетитель переходит к контактным сведениям и правовой информации, а кнопки обращения приводят на существующую страницу контактов.

**Blocked by:** 02.

Все требования спецификации миграции и ограничения по сохранности старого проекта действуют для этой задачи. Проверки включаются в результат задачи; отдельная задача приёмки не заменяет их.

## Acceptance criteria

- [x] Страница контактов показывает актуальное для текущего проекта содержание; реальные контакты не выдуманы вместо отсутствующих значений.
- [x] Ссылки телефона и почты формируются только из подтверждённых данных; демонстрационные и неизвестные значения остаются текстом согласно текущему поведению.
- [x] Кнопки обращения ведут непосредственно к контактам без восстановленных параметров темы обращения и несуществующих якорей.
- [ ] Правовая страница доступна напрямую; ссылка на раздел о персональных данных приводит к существующему якорю personal-data.
- [x] Форма отправки, карта, блок входа и адаптер отправки сообщений не появляются.
- [ ] Проверены прямые ссылки, обновление страниц, мобильное отображение и клавиатурное управление.

## Comments

- Состав и зависимости согласованы пользователем. Публичные информационные страницы имеют приоритет перед редакционной частью; порядок номеров задаёт приоритет, а блокирующие связи — технические зависимости.

## Answer

6 ноября 2026 реализованы встроенные PHP-страницы `/contacts` и `/legal`
с общими шапкой, подвалом, хлебными крошками, метаданными и отдельными стилями.
Перенесены четыре неподтверждённых контактных значения как текст и сообщение
о подготовке правовой информации с якорем `personal-data`. Существующие CTA
уже ведут на `/contacts` без параметров/якорей и не требуют изменения.
Данные WordPress и старый стек не изменены. Коммитов не создано.

ESLint, типы web/cms, 12 существующих тестов, синтаксис HTTP-проверок и разбор
CSS прошли. Выполнены отдельные ревью стандартов и спецификации; исправлена
семантика списка определений контактов. HTTP-проверки не получили ответов
из-за `EACCES 127.0.0.1:8080`, Podman также недоступен, PHP CLI отсутствует.
Прямые открытия, обновления, правовой якорь в браузере, мобильный вид
и клавиатура требуют приёмки работающего WordPress; статус `ready-for-human`.
