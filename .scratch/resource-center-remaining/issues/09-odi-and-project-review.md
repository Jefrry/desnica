# 09: Собрать ОДИ и согласование проектов

**What to build:** Собрать две законченные страницы услуг, которые объясняют проектирование раздела ОДИ и согласование проектов, сохраняют утверждённую структуру и приводят посетителя к обращению без неподтверждённых обещаний.

**Blocked by:** 05: Собрать контакты, маршрут и сквозной контекст обращения.

**Status:** ready-for-agent

- [ ] Обе страницы имеют корректные breadcrumbs, единственный H1 и активное состояние раздела услуг.
- [ ] Страница ОДИ использует полное согласованное название услуги.
- [ ] Страница ОДИ содержит согласованные смысловые блоки и процесс из четырёх шагов.
- [ ] Страница ОДИ не получает отсутствующий в дизайне FAQ или дополнительную услугу.
- [ ] Страница согласования проектов соблюдает согласованный порядок вводного блока, процесса, материалов, результата, FAQ, связанных услуг и CTA.
- [ ] Два FAQ на странице согласования изначально закрыты и полностью доступны с клавиатуры.
- [ ] Ни одна страница не обещает гарантированное согласование, результат или срок.
- [ ] Все изображения используют подтверждённый материал либо явно маркированный preview-мок.
- [ ] Связанные услуги ведут только на существующие маршруты.
- [ ] CTA каждой страницы передаёт правильный allowlisted service в контактную форму.
- [ ] Mobile-композиция сохраняет все смысловые блоки и их порядок.
- [ ] Lint, проверка типов и production-сборка проходят.
