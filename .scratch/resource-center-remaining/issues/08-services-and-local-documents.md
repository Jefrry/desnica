# 08: Собрать каталог услуг и разработку локальных документов

**What to build:** Создать каталог из четырёх подтверждённых услуг и законченный путь по услуге разработки локальных документов от объяснения содержания услуги до FAQ и обращения.

**Blocked by:** 02: Собрать документы и годовую отчётность; 05: Собрать контакты, маршрут и сквозной контекст обращения.

**Status:** resolved

- [x] Каталог содержит корректные breadcrumbs, H1, лид и ровно четыре карточки поддерживаемых услуг.
- [x] Якорь списка услуг существует и доступен по прямой ссылке.
- [x] Каталог не содержит фильтров, поиска, цен, modal, пятой услуги или отдельного блока процесса.
- [x] Каждая карточка ведёт только на существующую страницу услуги.
- [x] Страница локальных документов соблюдает согласованный порядок intro, назначение, состав работы, результат, FAQ, связанные услуги и CTA без отдельного блока этапов.
- [x] Смысловой текст берётся из утверждённого содержания, а не распознаётся из мелкого текста макета.
- [x] Результат услуги остаётся видимым и содержательным на mobile.
- [x] Два FAQ работают независимо от других экземпляров; первый вопрос имеет согласованное начальное состояние.
- [x] Документные действия используют общий честный контракт чтения и скачивания.
- [x] CTA передаёт allowlisted тему услуги в контактную форму.
- [x] Страница не обещает цену или гарантированный срок.
- [x] Lint, проверка типов и production-сборка проходят.

## Answer

Собран каталог из четырёх услуг с прямым якорем, карточками только на поддерживаемые маршруты и общей контактной полосой. Для ещё не развёрнутых детальных сценариев добавлены минимальные страницы на утверждённых заголовках и лидах, поэтому переходы каталога не заканчиваются ошибкой.

Страница разработки локальных документов содержит согласованный рассказ об аудитории, составе работы и результате, два FAQ, связанные услуги и переход к контактам. Первый вопрос открыт изначально; второй проверен с клавиатуры. На ширинах 1440, 390 и 320 CSS px сохранены порядок и содержание, горизонтальной прокрутки нет.

Lint, полная проверка типов и production-сборка web/CMS проходят.
