# 08: Собрать каталог услуг и разработку локальных документов

**What to build:** Создать каталог из четырёх подтверждённых услуг и законченный путь по услуге разработки локальных документов от объяснения процесса до чтения материалов, FAQ и обращения.

**Blocked by:** 02: Собрать документы и годовую отчётность; 05: Собрать контакты, маршрут и сквозной контекст обращения.

**Status:** ready-for-agent

- [ ] Каталог содержит корректные breadcrumbs, H1, лид и ровно четыре карточки поддерживаемых услуг.
- [ ] Якорь списка услуг существует и доступен по прямой ссылке.
- [ ] Каталог содержит согласованный процесс из трёх шагов без фильтров, поиска, цен, modal или пятой услуги.
- [ ] Каждая карточка ведёт только на существующую страницу услуги.
- [ ] Страница локальных документов соблюдает согласованный порядок intro, назначение, процесс, исходные материалы, результат, FAQ, связанные услуги и CTA.
- [ ] Смысловой текст берётся из утверждённого содержания, а не распознаётся из мелкого текста макета.
- [ ] Результат услуги остаётся видимым и содержательным на mobile.
- [ ] Два FAQ работают независимо от других экземпляров; первый вопрос имеет согласованное начальное состояние.
- [ ] Документные действия используют общий честный контракт чтения и скачивания.
- [ ] CTA передаёт allowlisted тему услуги в контактную форму.
- [ ] Страница не обещает цену или гарантированный срок.
- [ ] Lint, проверка типов и production-сборка проходят.
