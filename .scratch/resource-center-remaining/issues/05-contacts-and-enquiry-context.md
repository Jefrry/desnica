# 05: Собрать контакты, маршрут и сквозной контекст обращения

**What to build:** Создать законченный путь от CTA услуги, программы или сотрудничества до доступной контактной формы, включая контакты, маршрут, безопасный preview-адаптер отправки и правовую точку назначения.

**Blocked by:** 01: Укрепить базовые контракты и режим предпросмотра.

**Status:** ready-for-agent

- [ ] Услуги передают allowlisted `service`, программы — allowlisted `program`, общие действия — allowlisted `topic`; приоритет равен service, затем program, затем topic.
- [ ] Неизвестные query-значения игнорируются и не вставляются в HTML; персональные данные никогда не помещаются в URL.
- [ ] Выбранная тема открыто показана над сообщением и не подменяет текст посетителя.
- [ ] Контактные сведения создают tel/mailto только для подтверждённых значений; mock и неизвестные значения остаются обычным текстом.
- [ ] Location-блок содержит изображение входа, текст маршрута и дополнительную схему, не запрашивает геолокацию и не создаёт реальную маршрутную ссылку без адреса.
- [ ] Контактная страница использует один экземпляр формы и согласованный порядок блоков на desktop и mobile.
- [ ] Форма содержит постоянные labels, необязательное имя, обязательные email, сообщение и согласие.
- [ ] Ограничения равны 100 символам для имени, 254 для email и 5000 для сообщения; сообщение проверяется после trim.
- [ ] Первый ошибочный submit показывает связанную с полями сводку и переводит в неё фокус; локальные ошибки корректируются после взаимодействия.
- [ ] Pending сохраняет данные и блокирует повтор; server error сохраняет данные и разрешает повтор.
- [ ] Реальный success возможен только после подтверждения сервером.
- [ ] Preview-адаптер детерминированно демонстрирует задержку, ошибку и mock-success, не выполняя внешних запросов и не заявляя реальную доставку.
- [ ] Пользовательские данные не пишутся в console, URL или постоянное локальное хранилище.
- [ ] Ссылка согласия ведёт на существующую правовую страницу и якорь personal-data.
- [ ] Preview-правовой текст явно обозначен как черновой; production без утверждённого текста сообщает, что информация готовится, и не включает реальную отправку.
- [ ] Lint, проверка типов и production-сборка проходят.
