# 06: Собрать главную страницу

**What to build:** Собрать главную страницу «Ресурсного центра» как законченный маршрут от знакомства с организацией до услуг, публикаций и обращения.

**Blocked by:** 03: Собрать архив публикаций с заменяемым источником; 05: Собрать контакты, маршрут и сквозной контекст обращения.

**Status:** resolved

- [x] Главная использует публичное название и согласованные title/description.
- [x] Hero содержит единственный H1, лид, переходы к услугам и разделу «О нас» и полный цветной логотип без перерисовки.
- [x] Блок о центре содержит согласованный текст, три ссылки и честное состояние отсутствующего изображения команды.
- [x] На mobile порядок блока о центре равен текст, изображение, ссылки.
- [x] Команда содержит ровно три согласованные карточки и переходит к компактным строкам на mobile.
- [x] Раздел последних публикаций показывает три наиболее свежие записи активного источника и ссылку на архив.
- [x] При пустом источнике раздел публикаций показывает честное empty-состояние без фиктивных карточек.
- [x] Контактная полоса ведёт к существующей странице контактов и не превращает неподтверждённые контакты в активные ссылки.
- [x] Секции следуют порядку hero, о центре, команда, последние публикации, контактная полоса.
- [x] Композиция проверена на desktop и mobile без горизонтальной прокрутки.
- [x] Lint, проверка типов и production-сборка проходят.

## Answer

Главная страница собрана в согласованном порядке из общих компонентов. Hero использует публичное название, утверждённые тексты, два перехода и исходный цветной логотип. Блок о центре, три роли команды, три последние публикации активного источника и контактная полоса работают как единый маршрут.

Для публикаций предусмотрены загрузка, пустой список и ошибка с повторной попыткой. Контактные значения без подтверждённых адресов остаются обычным текстом, а кнопка ведёт на существующую страницу контактов. Данные команды вынесены в общий набор для повторного использования на странице «О нас».

Проверены ширины 1440, 390 и 320 CSS px, порядок мобильного блока, единственный H1, количество карточек и отсутствие горизонтальной прокрутки. Lint, полная проверка типов и production-сборка web/CMS прошли.

## Comments

- Фотографии команды не предоставлены; до их появления используются честно подписанные состояния отсутствующих изображений.
- Конфликт с ADR 0001: для отсутствующих фотографий предусмотрены локальные заменители, но файлы для `team-meeting` и трёх карточек команды не предоставлены. Пункт завершён с недоступными состояниями вместо неподтверждённых изображений.
