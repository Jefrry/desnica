# 03: Собрать архив публикаций с заменяемым источником

**What to build:** Создать полноценный архив «Новости», который работает с единым источником публикаций, поддерживает настоящую пагинацию и все состояния коллекции, а позднее переключается с моков на существующую CMS без переделки страницы.

**Blocked by:** 01: Укрепить базовые контракты и режим предпросмотра.

**Status:** resolved

- [x] Определён единый типизированный контракт источника публикаций для списка, отдельной публикации и pagination metadata.
- [x] Preview-источник возвращает двенадцать согласованных публикаций с размером страницы шесть и двумя страницами.
- [x] CMS-адаптер сохраняет существующий API и возвращает вызывающему коду реальные page, pageSize, pageCount и total.
- [x] Ошибка CMS не заменяется демонстрационными публикациями.
- [x] Архив показывает шесть карточек на странице: три колонки на desktop, две на tablet и согласованный mobile-список.
- [x] Первая страница использует базовый адрес архива, последующие — query `page=N`; отдельный маршрут вида `page/N` не создаётся.
- [x] Пагинация содержит только действия «Назад» и «Далее» без номеров страниц и многоточий; ссылки корректно отключаются на границах.
- [x] При единственной странице пагинация не выводится.
- [x] Нечисловое или отрицательное значение нормализуется к первой странице с исправлением URL.
- [x] Числовая страница за пределами архива показывает честное состояние отсутствия.
- [x] Реализованы pending, empty, error, retry и success без вывода внутренних сообщений сервиса.
- [x] После явной смены страницы объявляется её номер и фокус переходит к заголовку списка.
- [x] Переход в публикацию сохраняет известную страницу архива и позволяет вернуться к ней и приблизительной позиции списка.
- [x] Title и canonical отражают выбранную действительную страницу архива.
- [x] Lint, проверка типов и production-сборка проходят.

## Answer

Добавлен единый типизированный источник публикаций для списка и детальной страницы. Preview-режим использует 12 согласованных публикаций и две страницы по 6; CMS-адаптер передаёт параметры пагинации, сохраняет метаданные и обложки, а при ошибке показывает честное error-состояние без fallback на демонстрационные данные.

Архив собран с адаптивной сеткой, доступной URL-пагинацией, pending/empty/error/retry/missing-page состояниями, нормализацией неверного query, фокусом и объявлением номера после явного перехода. Ссылка в публикацию сохраняет страницу и якорь карточки для возврата. Title и canonical зависят от действительной страницы.

Lint, полная проверка типов и production-сборка web/CMS прошли. В браузере проверены страницы 1 и 2, возврат из публикации, неверные номера, отсутствие fallback при ошибке CMS и reflow без горизонтальной прокрутки на 320/390/768/1440 px. NVDA/VoiceOver вручную не проверялись.
