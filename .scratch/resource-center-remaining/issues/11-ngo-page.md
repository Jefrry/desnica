# 11: Собрать страницу работы с НКО

**What to build:** Собрать законченную страницу поддержки НКО с тремя направлениями, доступными демонстрационными материалами, понятным процессом сотрудничества и рабочим CTA.

**Blocked by:** 02: Собрать документы и годовую отчётность; 05: Собрать контакты, маршрут и сквозной контекст обращения.

**Status:** resolved

- [x] Страница имеет корректные breadcrumbs, единственный H1, intro и согласованный вводный текст.
- [x] Раздел поддержки содержит три информационные карточки: консультации, обмен опытом и совместные инициативы.
- [x] Карточки не выглядят интерактивными и не создают переходы, если отдельных страниц нет.
- [x] Раздел материалов содержит ровно три документные строки и не добавляет несуществующий общий архив.
- [x] Preview использует безопасные демонстрационные материалы через общий документный контракт.
- [x] Production без реальных материалов показывает честные недоступные состояния.
- [x] Блок «Как начать сотрудничество» и связанный CTA не выводятся.
- [x] На mobile карточки становятся компактными строками, а документные действия располагаются после текста.
- [x] Lint, проверка типов и production-сборка проходят.

## Answer

Собран маршрут `/ngo` с согласованными breadcrumbs, intro, тремя неинтерактивными направлениями поддержки и тремя материалами на общем документном контракте. Блок «Как начать сотрудничество» и связанный CTA удалены по уточнению задачи.

В preview доступны безопасные локальные материалы в текстовом формате без имитации PDF или DOCX; production показывает честное недоступное состояние. Пользовательские подписи о тестовых, демонстрационных или preview-данных не добавлялись. Из-за ранее принятого решения по задаче 05 CTA не передаёт удалённый контекст обращения и не использует отсутствующий якорь формы.

Lint, полная проверка типов и production-сборка web/CMS прошли. Desktop-композиция проверена в браузере; структура страницы и отсутствие горизонтального переполнения проверены программно. Полноценная ручная mobile-проверка и NVDA/VoiceOver не выполнялись.
