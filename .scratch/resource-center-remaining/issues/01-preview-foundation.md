# 01: Укрепить базовые контракты и режим предпросмотра

**What to build:** Подготовить надёжную основу для оставшейся реализации: устранить обнаруженные расхождения в готовых общих компонентах и добавить единый режим предпросмотра, в котором безопасные демонстрационные материалы последовательно используются на всех маршрутах.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Уведомления об ошибке и успехе объявляются вспомогательным технологиям только после фактического изменения состояния, а не только из-за первоначального появления компонента.
- [x] Карточки услуг принимают только четыре подтверждённых маршрута услуг и не создают переход к произвольному адресу.
- [x] Список принципов принимает ровно три элемента или явно отклоняет неверную конфигурацию.
- [x] Список шагов принимает только три или четыре элемента и не применяет случайную раскладку к другой длине.
- [x] Режим предпросмотра включается одной конфигурацией окружения для всего развёртывания и сохраняется при переходах между страницами.
- [x] Режим предпросмотра не выводит глобальную плашку; отдельные демонстрационные материалы сохраняют честные подписи там, где это необходимо.
- [x] Страницы режима предпросмотра получают запрет индексации.
- [x] Вне режима предпросмотра демонстрационные данные не включаются автоматически, в том числе при ошибке внешнего источника.
- [x] Определены общие типизированные контракты для безопасных демонстрационных фотографий, документов, видео, контактов, правового текста и состояний интеграций.
- [x] Демонстрационные материалы явно отличаются от подтверждённых и не заявляют фактическую, юридическую или операционную достоверность.
- [x] Существующие header, navigation, mobile dialog, layout и визуальная тема не регрессируют.
- [x] Lint, проверка типов и production-сборка проходят.

## Answer

Добавлен единый deployment-флаг `NUXT_PUBLIC_PREVIEW_MODE` и `noindex` для обычных и ошибочных страниц. Глобальная плашка предпросмотра удалена; отдельные демонстрационные материалы сохраняют собственные честные подписи. Введены типизированные контракты подтверждённых, демонстрационных и отсутствующих фотографий, документов, видео, контактов, правового текста и интеграций, а выбор preview/production отделён от ошибок внешних источников.

Исправлены контракты `InlineNotice`, карточек услуг, списка принципов и списка шагов. Lint, полная проверка типов и production-сборка web/CMS прошли. SSR вручную проверен с включённым и выключенным preview-флагом: `noindex` появляется только в preview, общий header/main/footer сохраняются. NVDA/VoiceOver вручную не проверялись.
