# 02: Собрать документы и годовую отчётность

**What to build:** Дать посетителю законченные страницы документов и отчётности: документы можно читать на сайте независимо от наличия файла, выбранный документ и год сохраняются в URL и истории, а демонстрационные материалы честно обозначены.

**Blocked by:** 01: Укрепить базовые контракты и режим предпросмотра.

**Status:** resolved

- [x] Документная строка показывает название, описание и доступные метаданные без выдуманного размера, формата или даты.
- [x] Действие чтения ведёт к существующей текстовой версии; действие скачивания существует только при наличии подтверждённого или явно демонстрационного файла.
- [x] Недоступное действие визуально отличается и не получает пустой или фиктивный адрес.
- [x] На странице документов показаны три согласованных документа и доступное оглавление из четырёх реальных якорей.
- [x] Выбранный документ отражается в query и реальном якоре reader, поддерживает прямое открытие и историю назад/вперёд.
- [x] После явного выбора документа фокус переходит на заголовок reader; неизвестный идентификатор показывает понятное состояние отсутствия.
- [x] Текстовая версия документа выводится структурированно и безопасно, не создаёт второй H1 и не требует PDF.
- [x] Нативный выбор года имеет постоянную подпись, содержит 2025, 2024 и 2023 в обратном хронологическом порядке и отражает значение в query.
- [x] Смена года обновляет отчёт, обложку, действия и архив; архив не повторяет выбранный год.
- [x] После смены года фокус остаётся на select и объявляется краткий статус о показанном годе.
- [x] Неизвестный год показывает пояснение и не подменяется молча другим отчётом.
- [x] Страницы документов и отчётности соответствуют утверждённому порядку блоков на desktop и mobile.
- [x] Preview использует явно обозначенные демонстрационные документы и отчёты; production без реальных файлов показывает честные ограничения.
- [x] Lint, проверка типов и production-сборка проходят.

## Answer

Добавлены общие компоненты документной строки, безопасного текстового reader, выбора года и панели отчёта, а также маршруты `/about/documents` и `/about/reports`. Query/hash-состояние поддерживает прямое открытие, back/forward, явные состояния неизвестных значений и требуемое управление фокусом.

Preview показывает только явно обозначенные демонстрационные текстовые материалы и обложку; неподтверждённые PDF, размеры, даты и финансовые данные не создаются. Production показывает честные недоступные состояния без автоматической подмены моками. Lint, полная проверка типов и production-сборка web/CMS прошли. Маршруты проверены вручную на 1440, 390 и 320 CSS px; NVDA/VoiceOver вручную не проверялись.
