# 04: Собрать детальную страницу публикации

**What to build:** Дать посетителю полноценную детальную статью публикации с доступной структурой, оглавлением, медиа и расшифровкой, сохранив совместимость с текущим строковым содержимым CMS и существующим поведением ошибок.

**Blocked by:** 03: Собрать архив публикаций с заменяемым источником.

**Status:** ready-for-agent

- [ ] Публикация остаётся единственной редакционной сущностью; «статья» является её детальным представлением.
- [ ] Загрузка по slug, корректный not-found и ошибка сервиса сохранены для CMS-источника.
- [ ] Строковое содержимое существующей CMS выводится безопасным текстом через явный адаптер без произвольного HTML.
- [ ] Preview-источник поддерживает упорядоченные блоки абзаца, H2, изображения, цитаты, списка и видео.
- [ ] На странице ровно один H1; содержимое статьи начинается с H2 и использует комфортную ширину чтения.
- [ ] Основная демонстрационная статья содержит полное согласованное наполнение и четыре якоря: start, solutions, video и next.
- [ ] Оглавление содержит только существующие H2, работает при прямом hash, клике и истории назад/вперёд и корректно управляет фокусом.
- [ ] Обложка, второе изображение, цитата и видеоблок остаются в потоке на desktop и mobile.
- [ ] Видео не запускается автоматически; отсутствующий источник не изображает работающий плеер или ложную длительность.
- [ ] Субтитры и аудиоописание показываются только при наличии соответствующих данных.
- [ ] Расшифровка раскрывается доступной кнопкой с ясным названием и состоянием expanded.
- [ ] Связанные публикации ведут на существующие preview- или CMS-slug.
- [ ] «Все новости» возвращает к известной странице архива, иначе к первой странице.
- [ ] Title, description, breadcrumbs и метаданные используют только доступные данные публикации.
- [ ] Lint, проверка типов и production-сборка проходят.
