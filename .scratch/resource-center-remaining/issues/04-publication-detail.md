# 04: Собрать детальную страницу публикации

**What to build:** Дать посетителю полноценную детальную статью публикации с доступной структурой, оглавлением и изображениями, сохранив совместимость с текущим строковым содержимым CMS и существующим поведением ошибок. Видеофункционал отложен по решению владельца.

**Blocked by:** 03: Собрать архив публикаций с заменяемым источником.

**Status:** resolved

- [x] Публикация остаётся единственной редакционной сущностью; «статья» является её детальным представлением.
- [x] Загрузка по slug, корректный not-found и ошибка сервиса сохранены для CMS-источника.
- [x] Строковое содержимое существующей CMS выводится безопасным текстом через явный адаптер без произвольного HTML.
- [x] Preview-источник поддерживает упорядоченные блоки абзаца, H2, изображения, цитаты и списка.
- [x] На странице ровно один H1; содержимое статьи начинается с H2 и использует комфортную ширину чтения.
- [x] Основная демонстрационная статья содержит согласованное текстовое наполнение и три якоря: start, solutions и next.
- [x] Оглавление содержит только существующие H2, работает при прямом hash, клике и истории назад/вперёд и корректно управляет фокусом.
- [x] Обложка, второе изображение и цитата остаются в потоке на desktop и mobile.
- [x] Видеоблок, плеер, субтитры, аудиоописание и расшифровка на данном этапе не реализуются.
- [x] Связанные публикации ведут на существующие preview- или CMS-slug.
- [x] «Все новости» возвращает к известной странице архива, иначе к первой странице.

## Answer

Добавлена типизированная модель упорядоченных блоков публикации и общие компоненты ArticleBody и ArticleMeta. Бизнес-логика детальной страницы вынесена в `usePublicationDetailPage`, а двухколоночная раскладка статьи собрана на flexbox. Строковое содержимое CMS проходит через отдельный адаптер и выводится только как безопасный текст; существующие загрузка по slug, 404 и ошибка сервиса сохранены.

Preview-публикация N01 получила согласованное текстовое содержание, три H2-якоря, обложку, второе изображение, цитату и две связанные публикации. Видеофункционал и связанные с ним модели и компоненты удалены по решению владельца. Страница использует один H1, узкую колонку чтения, метаданные и canonical, а возврат «Все новости» сохраняет известные страницу и позицию архива.

Lint, полная проверка типов и production-сборка web/CMS прошли. В браузере проверены 1440, 390 и 320 CSS px, прямой hash, перевод фокуса на H2, возврат со второй страницы архива и неизвестный slug. NVDA/VoiceOver вручную не проверялись.
