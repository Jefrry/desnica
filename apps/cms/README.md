# CMS

Strapi-приложение в составе pnpm monorepo. Установка, запуск и проверки описаны в
[корневом README](../../README.md).

## News API

Публично доступны только опубликованные новости:

- `GET /api/news` — список;
- `GET /api/news/:slug` — одна новость по стабильному slug.

Анонимные `POST`, `PUT` и `DELETE` запрещены. Slug можно отредактировать вручную;
при создании он автоматически транслитерируется из заголовка, а конфликтующие
значения получают числовой суффикс (`novaya-statya-2`).
