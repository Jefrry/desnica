# Web

Nuxt-приложение в составе pnpm monorepo. Установка, запуск и проверки описаны в
[корневом README](../../README.md).

Обработчик `renderPublicationMarkdown(content, cmsBaseUrl)` возвращает очищенный
`html` и `toc` (пункты `{ id, label }` для H2 после нормализации). Передавайте
публичный абсолютный адрес CMS одинаково на сервере и в браузере: относительно
него разрешаются адреса изображений; обычные ссылки и якоря сохраняются.
Обработчик не зависит от Nuxt runtime и не изменяет исходный Markdown.

Настройки и расширения соответствуют предпросмотру Strapi 5.55.1, включая
буквальные `\n` и сноски без переходов. Видеовставки исключены. Идентификаторы
заголовков генерируются после очистки HTML, из этого же дерева строится оглавление.
Страница статьи обрабатывает полный текст CMS один раз: `ArticleBody` выводит
очищенный HTML, а `ArticleToc` получает оглавление из того же результата.
Локальные стили тела статьи оформляют Markdown и расширения Strapi в теме сайта;
изображения ограничены шириной колонки, таблицы и код прокручиваются внутри неё.
Структурированные блоки встроенных материалов сохраняют прежнее отображение.

Проверки обработчика: `pnpm test` из корня репозитория. Они включают сравнение
серверного результата с браузерной сборкой в DOM-окружении.
