## Agent skills

### Issue tracker

Задачи хранятся локально в Markdown-файлах внутри `.scratch/`. См. `docs/agents/issue-tracker.md`.

### Triage labels

Используются стандартные метки: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. См. `docs/agents/triage-labels.md`.

### Domain docs

Используется единая доменная документация уровня репозитория. См. `docs/agents/domain.md`.
