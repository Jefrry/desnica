# Источники содержимого

По решению от 20 октября 2026 года отдельный режим предпросмотра удалён.
Страницы получают публикации через единый контракт источника, который
обслуживается API Strapi. Главная, архив и страницы статей показывают только
опубликованные записи CMS; пустой список и ошибка API не подменяются моками. Остальное
содержимое сайта остаётся встроенным согласно утверждённому дизайну.

Отсутствующие фотографии, документы, видео, контакты, правовые тексты и внешние
интеграции представлены безопасными локальными моками через те же контракты,
по которым их позднее заменят реальные данные. Моки явно маркируются,
не заявляют юридическую или фактическую достоверность и не выполняют внешних
действий; форма использует детерминированный адаптер для состояний успеха,
ошибки и задержки. Запрет индексации включён по умолчанию для обоих сервисов
и управляется независимо от содержимого.
