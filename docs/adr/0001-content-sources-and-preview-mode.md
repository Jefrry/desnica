# Источники содержимого и режим предпросмотра

CMS управляет только публикациями. Страницы получают публикации через единый контракт источника: в явно включённом конфигурацией окружения режиме предпросмотра его обслуживают моковые данные, а при последующем подключении — адаптер существующей CMS; ошибка CMS не включает моки автоматически. Остальное содержимое сайта остаётся встроенным согласно утверждённому дизайну.

Отсутствующие фотографии, документы, видео, контакты, правовые тексты и внешние интеграции в предпросмотре представлены безопасными локальными моками через те же контракты, по которым их позднее заменят реальные данные. Моки явно маркируются, не заявляют юридическую или фактическую достоверность и не выполняют внешних действий; форма использует детерминированный адаптер для состояний успеха, ошибки и задержки. Вне предпросмотра отсутствующие материалы остаются честными ограничениями. Режим предпросмотра заметно маркируется и не индексируется.
