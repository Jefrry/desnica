# PHP и WordPress для развёртывания на Timeweb

По решению пользователя от 5 ноября 2026 года новая версия сайта разрабатывается на PHP 8 и строго WordPress 6.7.1 для установки на виртуальный хостинг Timeweb загрузкой файлов по FTP. Это заменяет выбор Strapi как источника публикаций из ADR 0001 для новой реализации: WordPress будет управлять публикациями, а прочее содержимое пока остаётся встроенным. Внешний вид и бизнес-правила сохраняются; старый проект остаётся рядом без удаления файлов, публичная часть имеет первый приоритет.

Локально весь новый стек, включая PHP, WordPress и MySQL, запускается в контейнерах через Podman с чистой базой, без переноса публикаций и медиа из Strapi. Это позднее явное уточнение пользователя заменяет ранние упоминания Docker как средства локального запуска: инструкции и приёмка ориентированы на Podman, Docker Desktop и Docker Engine не обязательны. По уточнению пользователя WordPress на хостинге чистый, предположительно с базовыми настройками. Планируется подключать тему и плагин к нему штатным способом после проверки установки; заменять его базу локальной автоматически нельзя. Точная версия PHP 8.x, MySQL и политика обновления ядра ещё требуют уточнения.

По явному выбору пользователя применяется стандартная роль WordPress «Автор», без прежнего расширения прав на редактирование чужих публикаций. Это согласованное изменение редакционного поведения относительно Strapi. Для Markdown выбран готовый бесплатный Markup Markdown с обязательной проверкой совместимости на WordPress 6.7.1; конкретная версия плагина пока не утверждена. Пользователь подтвердил, что авторы не будут пользоваться скринридером, поэтому документированное ограничение редактора не блокирует выбор. Требования к доступности публичного сайта сохраняются.
