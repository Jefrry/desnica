# Трекер задач: локальные Markdown-файлы

Задачи и спецификации этого репозитория хранятся в виде Markdown-файлов в `.scratch/`.

## Соглашения

- Одна функция на каталог: `.scratch/<feature-slug>/`
- Спецификация: `.scratch/<feature-slug>/spec.md`
- Каждая задача реализации хранится отдельно: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Нумерация начинается с `01`; объединённый файл со всеми задачами не используется
- Состояние триажа записывается строкой `Status:` в начале файла задачи
- Комментарии и история обсуждения добавляются в конец файла под заголовком `## Comments`

## Публикация в трекер задач

Если навык просит опубликовать материал в трекере, создать новый файл в `.scratch/<feature-slug>/`, при необходимости создав каталог.

## Получение задачи

Прочитать файл по указанному пути. Обычно пользователь передаёт путь или номер задачи напрямую.

## Операции wayfinding

Карта хранится отдельно, а каждой задаче соответствует дочерний файл.

- Карта: `.scratch/<effort>/map.md`
- Дочерняя задача: `.scratch/<effort>/issues/NN-<slug>.md`
- Строка `Type:` содержит тип: `research`, `prototype`, `grilling` или `task`
- Строка `Status:` содержит состояние: `claimed` или `resolved`
- Блокировки задаются строкой `Blocked by: NN, NN`
- Задача разблокирована, когда все перечисленные задачи имеют статус `resolved`
- Для выбора следующей задачи просмотреть `.scratch/<effort>/issues/` и взять первую по номеру открытую, разблокированную и незанятую задачу
- Перед началом работы установить `Status: claimed` и сохранить файл
- При завершении добавить ответ под заголовком `## Answer`, установить `Status: resolved` и добавить краткий итог со ссылкой в раздел Decisions-so-far файла `map.md`
