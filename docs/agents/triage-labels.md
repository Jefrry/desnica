# Метки триажа

Навыки используют пять канонических ролей триажа. Эта таблица сопоставляет роли с фактическими метками трекера репозитория.

| Каноническая роль | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется оценка сопровождающего |
| `needs-info` | `needs-info` | Ожидается дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Когда навык упоминает роль триажа, использовать соответствующую метку из таблицы.
